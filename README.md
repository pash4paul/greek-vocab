# Ελληνικά — тренажёр греческих слов

Интервальные повторения (FSRS) поверх словаря в YAML. Приложение статическое,
прогресс хранится в браузере, деплой — GitHub Pages.

## Как это работает

Одно слово порождает **до четырёх карточек**, у каждой свой независимый график:

| Ступень | Что делаешь | Открывается |
|---|---|---|
| `recognize` | видишь греческое слово → выбираешь перевод | сразу |
| `listen` | слышишь слово → выбираешь перевод | когда закрепилась предыдущая |
| `produce` | видишь перевод → набираешь по-гречески | когда закрепилась предыдущая |
| `cloze` | вставляешь слово в предложение | когда закрепилась предыдущая |
| `case` | ставишь существительное в нужный падеж | когда закрепилась предыдущая |

Ступени открываются по очереди, а не разом: иначе 8 новых слов в день —
это сразу 32 новые карточки, и через неделю нагрузка становится неподъёмной.
Следующая ступень появляется, только когда предыдущая вышла из фазы обучения.

Расписание считает **FSRS** — модель памяти, которая подбирает интервал под
целевое удержание (по умолчанию 90%). Она экономнее классического SM-2:
меньше повторений при том же результате.

Внутри сессии новые слова перемешаны с повторениями, а не идут блоком —
чередование запоминается лучше, чем зубрёжка одной темы подряд.

## Добавить слова

Положи новый файл в `data/` (или дополни существующий):

```yaml
topic: Еда
lesson: "05"

words:
  - el: ψωμί
    article: το          # обязателен для существительных: род учится вместе со словом
    ru: хлеб
    pos: noun            # noun | verb | adj | adv | phrase | prep | pron | num | other
    forms:
      plural: ψωμιά
    example: Θέλω ένα ψωμί.
    exampleRu: Я хочу хлеб.
    note: подсказка или мнемоника
    tags: [магазин]
```

Обязательны только `el` и `ru`. Каждое дополнительное поле включает новые
возможности: `example` — упражнение с пропуском, `forms` — таблицу форм на обороте,
`article` — проверку рода при вводе.

## Формы: писать не нужно

Множественное число, спряжения и роды выводятся при сборке по регулярным
правилам — для большинства слов `forms` можно не заполнять вообще:

```
ο λογαριασμός → οι λογαριασμοί      πληρώνω → πληρώνεις, πληρώνει, πληρώνουμε…
το πορτοκάλι  → τα πορτοκάλια       νόστιμος → νόστιμη, νόστιμο
```

Правила знают и про сдвиг ударения: `το μάθημα → τα μαθήματα`, а не
«μάθηματα» — тонос не может стоять дальше третьего слога от конца.

Если формы всё же **написаны руками**, скрипт их не подменяет, а сверяет
с правилом. Расхождение — это либо опечатка, либо настоящее исключение:

```
⚠ 02-verbs.yaml [τρώω]: present — по правилу «τρώω · τρώεις · τρώει…»,
  в файле «τρώω · τρως · τρώει…». Опечатка? Если слово неправильное,
  добавь irregular: true
```

Флаг `irregular: true` глушит предупреждение и ставит в приложении пометку
«неправильное». Смысл в том, что ни одно расхождение не остаётся незамеченным:
оно либо исправлено, либо признано осознанно.

```yaml
  - el: τρώω
    ru: есть, кушать
    pos: verb
    irregular: true
    forms:
      present: [τρώω, τρως, τρώει, τρώμε, τρώτε, τρώνε]
```

## Падежи

Для существительных с артиклем строится полная таблица — четыре падежа
в двух числах, сразу вместе с артиклем: он меняется не меньше самого слова
(`ο → τον → του`), и учить их порознь бессмысленно.

```
        ед. ч.              мн. ч.
им.     ο λογαριασμός       οι λογαριασμοί
род.    του λογαριασμού     των λογαριασμών
вин.    τον λογαριασμό      τους λογαριασμούς
зв.     λογαριασμέ          λογαριασμοί
```

Таблица видна на обороте карточки и в словаре, а упражнение `case` спрашивает
случайную клетку: «поставь в винительный, мн. ч.». Клетки, совпадающие
с исходной формой, не спрашиваются — у среднего рода винительный равен
именительному, и просить его значит просить переписать вопрос.

Какие падежи спрашивать — настройка (Настройки → Типы упражнений). **Родительный
по умолчанию выключен**: по учебнику он идёт позже, а формы его самые
непредсказуемые. Выключенный падеж просто не попадает в вопросы — таблица
на обороте и в словаре показывает его по-прежнему, прогресс по слову
сохраняется, и включить падеж обратно можно в любой момент.

**Родительный падеж множественного числа выводится не всегда, и это осознанно.**
У мужского и женского рода с ударением не на окончании он непредсказуем:
`ο πατέρας → των πατέρων`, но `ο άντρας → των αντρών`; `η μητέρα → των μητέρων`,
но `η πόρτα → των πορτών`. Правила здесь нет — есть история каждого слова.
Такие клетки остаются пустыми, скрипт их перечисляет, а заполняются они вручную:

```yaml
  - el: πόρτα
    article: η
    ru: дверь
    pos: noun
    cases:
      gen: [~, των πορτών]   # тильда — «оставить выведенное»
```

Ключ `cases` перекрывает любую клетку, не только пустую.

### Добор форм из Викисловаря

Пустые клетки можно не заполнять руками — их вытягивает скрипт:

```bash
npm run fetch:cases          # только слова с пустыми клетками
npm run fetch:cases -- --all # все существительные: полная сверка с правилами
```

Он ходит в `el.wiktionary.org`, разбирает таблицы склонения и кладёт результат
в `data/declensions.wiktionary.json`, откуда его подхватывает сборка.
Ответы кэшируются в `.cache/`, повторный запуск сеть не трогает.

Приоритет источников: **руками (`cases`) → Викисловарь → правила**. Викисловарь
подставляется только туда, где правило отказалось — выведенные формы он не
перетирает, а **расхождения с ними печатает отдельным списком**. Это работает
в обе стороны: сверка сразу нашла, что артикль `την` теряет `-ν` перед мягкими
согласными (`τη μέρα`, но `την πόρτα`) — правило у меня было упрощённое.

Где правило неприменимо, скрипт честно отказывается, а не угадывает:
глаголы на `-ώ` бывают двух спряжений (`αγαπώ` / `μπορώ`), женский род на
безударное `-η` даёт и `-ες`, и `-εις` (`νίκες` / `πόλεις`). В таких случаях
он попросит задать формы вручную.

Сами правила покрыты тестами на заведомо известных парах — `npm run test:morph`.

## Проверка перед коммитом

```bash
npm run check
```

Прогоняет тесты правил и валидирует словарь: опечатки в YAML, дубли между
файлами, существительные без артикля, примеры без самого слова, расхождения
с парадигмами. Идентификатор слова строится из греческой формы без ударений,
поэтому правка перевода или примера **не сбрасывает прогресс**.

## Команды

```bash
npm install
npm run dev        # локально, http://localhost:5173
npm run check      # только проверка словаря
npm run build      # прод-сборка в dist/
npm run test:morph # тесты правил словоизменения
npm run simulate   # прогон 60 учебных дней — видно, как растёт нагрузка
```

`npm run simulate` полезен, когда меняешь лимиты: сразу видно, во что
превратится дневная нагрузка через месяц.

## Деплой на GitHub Pages

1. Создай пустой репозиторий на GitHub.
2. `git init && git add -A && git commit -m "init"`
3. `git remote add origin git@github.com:<username>/<repo>.git && git push -u origin main`
4. В настройках репозитория: **Settings → Pages → Source → GitHub Actions**.

Дальше каждый пуш в `main` пересобирает и выкатывает сайт автоматически.
Адрес: `https://<username>.github.io/<repo>/`.

Открой его на телефоне и добавь на домашний экран — приложение ставится как
обычное и работает офлайн.

Для Cloudflare Pages или Netlify: команда сборки `npm run build`, каталог `dist`,
переменную `BASE_PATH` задавать не нужно (там сайт живёт в корне).

## Доработка через Claude Code

Проект рассчитан на то, что дорабатывать его будут через Claude Code — в том
числе люди, не пишущие код. Для этого в репозитории лежит:

- **`CLAUDE.md`** — контекст проекта: как устроены данные, какие правила нельзя
  нарушать, что уже проверено и переспрашивать не надо, на какие грабли
  наступали. Claude читает его сам при старте.
- **Навыки** — готовые сценарии для повторяющихся задач. Наберите слэш и имя:
  - `/add-words` — добавить слова из скриншотов урока, списка или текста;
  - `/publish` — выложить или обновить сайт.
- **Автопроверка** — после правки любого файла в `data/` сам запускается
  `npm run check`, и если словарь сломан, Claude узнает об этом сразу.

Самый частый сценарий выглядит так: сложить скриншоты в папку и написать
«добавь слова из этой папки». Всё остальное — разбор картинок, темы, артикли,
формы, проверка дубликатов — уже описано в навыке.

## Прогресс и данные

Прогресс лежит только в браузере (IndexedDB), на сервер ничего не уходит.
В настройках есть **экспорт/импорт** — им же переносится прогресс между
телефоном и ноутбуком. Делай экспорт время от времени: очистка данных сайта
в браузере сотрёт всё.

## Озвучка

Работает через системный синтез речи, без сети и без ключей. Нужен
установленный греческий голос:

- **macOS / iOS**: Настройки → Универсальный доступ → Устная речь → Голоса → Greek
- **Android**: обычно есть из коробки
- **Windows**: Параметры → Время и язык → Речь → Добавить голоса → Greek

Если голоса нет, упражнения на слух автоматически выключаются, остальные работают.
