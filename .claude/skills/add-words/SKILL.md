# Добавление слов в словарь

## 1. Собери материал

Если дали папку со скриншотами — прочитай **все** файлы по одному инструментом
Read. Не выборочно: пропущенный файл заметят не сразу, а слова будут потеряны.

Если дали текст или таблицу — работай с ними напрямую.

## 2. Разложи по темам

Один файл в `data/` — одна тема. Загляни в существующие файлы: подходящая тема
может уже быть, тогда дописывай в неё, а не создавай близкую по смыслу.

Учебники обычно группируют слова по частям речи (ΟΝΟΜΑΤΑ, ΡΗΜΑΤΑ, ΕΠΙΘΕΤΑ).
**Это не темы.** Раскладывай по смыслу — «Еда», «Город», «Работа», — иначе
в приложении фильтр по темам бесполезен, а отвлекающие варианты в упражнениях
подбираются хуже.

Имя файла — с числовым префиксом по порядку: `24-clothes.yaml`.

## 3. Пиши минимально

Обязательны только `el` и `ru`. Формы **не заполняй** — множественное число,
спряжения и роды выводятся при сборке:

```yaml
topic: Одежда
lesson: "24"

words:
  - el: πουκάμισο
    article: το          # у существительных обязателен: род учится вместе со словом
    ru: рубашка
    pos: noun            # noun verb adj adv phrase prep pron num conj other
    example: Το πουκάμισο είναι καθαρό.
    exampleRu: Рубашка чистая.
```

Существительные — без артикля в `el`, он отдельным полем. Глаголы — в 1 л. ед. ч.
(`μιλάω`). Прилагательные — в мужском роде.

Примеры добавляй там, где они естественны, и обязательно с `exampleRu`.
Пример включает упражнение с пропуском — но лучше десять хороших примеров,
чем сто натянутых.

## 4. Проверь

```bash
npm run check
```

Разбирай вывод целиком, не только ошибки:

- **Ошибка YAML про «Nested mappings»** — в значении есть двоеточие.
  Оберни всё значение в кавычки.
- **«дубль слова из …»** — слово уже есть. Не добавляй второй раз; если у него
  новое значение, допиши перевод к существующей записи.
- **«расхождение с правилами»** — форма, которую ты вписал руками, не совпала
  с парадигмой. Либо опечатка, либо настоящее исключение: тогда `irregular: true`
  и короткий `note`, чем оно необычно. **Правило под слово не подгоняй.**
- **«склонение не выведено» / «спряжение не выведено»** — правило отказалось.
  Впиши формы руками или пометь `irregular: true`.

## 5. Проверь дубликаты глубже

Валидатор ловит только точное совпадение «слово + часть речи». Прогони ещё:

```bash
node -e "
const d=require('./src/generated/deck.json');
const n=s=>s.normalize('NFD').replace(/[̀-ͅ]/g,'').normalize('NFC').toLowerCase().replace(/ς/g,'σ');
const byEl=new Map(), byRu=new Map();
for(const w of d.words){
  const a=n(w.el); (byEl.get(a)??byEl.set(a,[]).get(a)).push(w);
  const b=w.ru.toLowerCase().trim(); (byRu.get(b)??byRu.set(b,[]).get(b)).push(w);
}
for(const v of byEl.values()) if(v.length>1) console.log('одно слово, разные pos:', v.map(w=>w.display+'['+w.pos+']').join(' | '));
for(const v of byRu.values()) if(v.length>1) console.log('одинаковый перевод:', v.map(w=>w.display).join(' | '), '—', v[0].ru);
"
```

**Одинаковый перевод у двух слов — это баг.** На карточке RU→EL видно
«дешёвый», и какое из двух слов вводить — непонятно. Либо это одно слово в двух
написаниях (оставь одно, второе в `note`), либо синонимы — тогда разведи
уточнением: «русский (человек)» против «русский (относящийся к России)».

## 6. Добери падежи и досчитай

```bash
npm run fetch:cases   # формы, которые правила не выводят, из Викисловаря
npm run check
```

## 7. Отчитайся

Коротко и цифрами: сколько слов добавлено, разбивка по частям речи и темам,
сколько исключений помечено, какие дубликаты нашлись и что с ними сделано,
что осталось незаполненным и почему.

Пустая клетка — не всегда недоработка. У `η μπίρα` нет родительного
множественного и в Викисловаре, потому что греки его не употребляют. Так и скажи,
не выдумывай форму.
